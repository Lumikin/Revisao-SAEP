# Gerenciamento de serviços de agendamentos de uma oficina mecanica

## Requisitos Funcionais

1. O sistema deve permitir autenticação de usuarios;
2. O sistema deve permitir o registros de clientes;
3. O sistema deve permitir o registro de veiculos;
4. O sistema deve permitir associar o cliente com seus veiculos;
5. O sistema deve permitir agendar serviços com base no veiculo de cliente.
